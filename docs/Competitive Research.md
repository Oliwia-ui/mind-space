## Product conclusion

The proven minimum is quick Inbox capture, optional project grouping, an intentional Today list, and safe completion/reopening. Mind Space keeps that familiar model but gives it an original spatial layer: loose tasks float as thoughts, and a saved project is rendered as a constellation or galaxy. **MAKE IT MAKE SENSE** transforms the same data into ordinary usable task lists. The spatial view must always remain editable, local, and connected to real task data.

## Shared decisions

- Mind Space is personal, offline-first, and native to macOS; it has no account, cloud dependency, ads, or collaboration.
- It appends task events rather than overwriting history in a user-selected Obsidian vault.
- Stable task IDs are reserved for a future connection to the separate Focus Dive timer app.
